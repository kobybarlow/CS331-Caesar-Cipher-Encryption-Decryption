# Problem 2 Lab 3

## Requirements

Ruby installed on your computer<br>
A terminal or command prompt<br>
A text editor such as Visual Studio Code<br>

## How to Run

Open the project folder in Visual Studio Code.<br>
Open a terminal in VS Code.<br>
### Make sure Ruby is installed by running:<br>
ruby -v<br>
### Run the program using:<br>
ruby caesar_cipher.rb<br>
Enter a message when prompted.<br>
Enter an integer key when prompted.<br>
The program will display the encrypted message and the decrypted message.<br>
