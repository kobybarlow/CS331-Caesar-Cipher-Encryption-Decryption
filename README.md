# Problem 2 Lab 3

## Requirements

Ruby installed on your computer<br>
A terminal or command prompt<br>
A text editor such as Visual Studio Code<br>

## How to Run

Open the project folder in Visual Studio Code.
Open a terminal in VS Code.
Make sure Ruby is installed by running:
ruby -v
Run the program using:
ruby caesar_cipher.rb
Enter a message when prompted.
Enter an integer key when prompted.
The program will display the encrypted message and the decrypted message.
